# Enterprise DevSecOps Strategy

## Purpose

The objective of the DevSecOps strategy is to integrate security throughout the Software Development Lifecycle (SDLC) instead of treating it as a separate phase.

---

## Security Principles

- Shift Left Security
- Security by Design
- Least Privilege
- Continuous Security Validation
- Automated Security Checks

---

## Security Workflow

```
Developer

↓

GitHub

↓

Code Review

↓

Static Analysis

↓

Dependency Scan

↓

Container Scan

↓

Deployment Approval

↓

Production
```

---

## Security Goals

- Detect vulnerabilities early
- Prevent vulnerable deployments
- Standardize security practices
- Improve developer awareness
