# Service Level Objectives (SLOs)

## Purpose

Service Level Objectives define the operational targets that the platform aims to achieve.

---

## Platform SLOs

| Metric | Target |
|---------|---------|
| Availability | > 99.9% |
| Error Rate | < 1% |
| P95 Latency | < 200 ms |
| CPU Usage | < 80% |
| Memory Usage | < 85% |
| Pod Restart Count | 0 Unexpected Restarts |

---

## Why SLOs?

SLOs help Platform Engineers determine whether the platform is meeting expected performance and reliability goals.

If an SLO is violated, investigation and remediation should begin immediately.
