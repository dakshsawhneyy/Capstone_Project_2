# Capstone 2 - Enterprise Platform Engineering Strategy

## Project Overview
This project presents an enterprise DevOps platform strategy for a growing software organisation

The objective is to design a scalable, secure, observable, and cost-efficient platform capable of supporting hundreds of developers and multiple product teams.

## Objectives
- Standardize software delivery
- Build a GitOps-driven deployment strategy
- Design an Internal Developer Platform
- Improve observability
- Integrate security into the SDLC
- Optimize cloud costs
- Present architectural decisions to stakeholders

## Platform Architecture
```
Developers
        ↓
GitHub
        ↓
GitHub Actions
        ↓
Container Registry
        ↓
Kubernetes
        ↓
Argo CD
        ↓
Monitoring
        ↓
Executive Dashboard
```
